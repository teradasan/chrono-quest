# Chrono Quest - 仕様書

## 概要
スーパーファミコンのゼルダの伝説風アクションRPG（Webアプリ）

## 技術スタック
- フレームワーク: Phaser 3 (MIT)
- ビルド: Vite
- デプロイ: Vercel（静的サイト）
- セーブ: LocalStorage

## 画面解像度
960 x 540 px（16:9）、タイルサイズ 16px

---

## コントローラーマッピング

| ボタン | 通常時 | ロックオン中 | メニュー時 |
|--------|--------|--------------|-----------|
| 十字キー | 移動（8方向） | ストレイフ | カーソル |
| A | 攻撃 / インタラクト（コンテキスト依存） | 攻撃 | 決定 |
| B | 回避（ローリング） | 回避 | キャンセル |
| X | アイテム使用 | アイテム使用 | サブ操作 |
| Y | 武器ホットスワップ（2スロット切替） | 武器切替 | タブ切替 |
| L1 | ロックオン（押しっぱなし） | 解除 | - |
| L2 | ダッシュ（押しっぱなし） | ダッシュ | - |
| R1 | スキル1（アクティブ） | スキル1 | - |
| R2 | スキル2（アクティブ） | スキル2 | - |
| Start | システムメニュー | - | 閉じる |
| Select | マップ（ミニ/フル切替） | - | - |

### Aボタン インタラクト優先順位
1. ロックオン中 → 必ず攻撃
2. インタラクト対象が近距離にある → インタラクト（プロンプト表示）
3. それ以外 → 攻撃

### NPCの仕様
- NPCには攻撃当たり判定なし
- 敵とNPCが密集するマップ設計は行わない

## RPGステータス

| パラメータ | 説明 |
|-----------|------|
| Lv / EXP | 戦闘で経験値取得・レベルアップ |
| HP / HP最大 | 0でゲームオーバー |
| MP | スキル使用で消費・時間回復 |
| STR | 物理攻撃力 |
| DEF | 物理防御力 |
| AGI | 移動速度・回避成功率 |
| お金（G） | ショップ利用・装備強化 |
| 武器熟練度 | 武器種ごと・使用で成長・技解放 |
| スキル熟練度 | スキルごと・使用で成長 |

---

## スキルシステム

### アクティブスキル
- R1/R2 に各1つ装備
- MP消費で発動
- スキルポイントで習得・強化

### パッシブスキル
- 常時発動
- 取得数制限なし

### 武器熟練パッシブ
- 各武器熟練度が閾値を超えると自動解放

### 振り直し設定（constants.js で変更可能）
```js
SKILL_CONFIG = {
  mode: 'free',      // 'free' | 'gold' | 'item' | 'disabled'
  goldCost: 0,
  requiredItem: null,
}
```
